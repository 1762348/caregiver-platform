# 演示脚本（2–3 分钟录屏）

面向面试官/招聘方，按顺序展示三端闭环。建议 1080p、浏览器缩放 100%、手机尺寸窗口（430×932）。

## 录制前准备

```bash
cp .env.example .env
# 设置 DB_PASSWORD、JWT_SECRET，演示环境设置 SMS_FIXED_CODE=123456
docker compose up -d --build
```

- 打开 <http://localhost>，提前登录一次，确认首页正常
- 关闭无关标签页、通知；不要露出个人信息
- 录屏工具：OBS / Windows 自带录屏（Win+G）/ ScreenToGif

## 镜头 1：用户端预约（0:00–0:50）

| 时间 | 操作 | 讲解词 |
| --- | --- | --- |
| 0:00 | 首页 | “这是护工预约平台的用户端，服务类别、进行中订单、未读消息都来自真实接口。” |
| 0:08 | 点击「立即预约」 | “预约是四步向导：类别 → 日期时段 → 被照顾人 → 确认。” |
| 0:15 | 选「日常照料」，下一步 | “排班会实时校验剩余名额，已经被约满的时段不会返回。” |
| 0:25 | 选一个时段，下一步 | “名额通过数据库条件更新原子扣减，并发下不会超卖。” |
| 0:35 | 选被照顾人，确认预约 | “下单后进入待支付，30 分钟未支付会自动取消并释放名额。” |
| 0:45 | 订单详情 → 去支付 → 微信支付 | “支付走的是可替换的 PaymentGateway，当前是 Mock 实现。” |
